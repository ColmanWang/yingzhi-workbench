# 第一版本地验收

日期：2026-10-22。范围：本地网页、视频目录、任务队列、本地转写及已有卡片；AI 总结与 OCR 尚未接入。

## 验证结果

- 完整 Python 测试 134 项通过；工作台新增模块覆盖率 91%。
- 前端测试 16 项通过；语句 94.59%、分支 84.58%、函数 88.33%、行 98.5%。
- 生产构建通过；官方 npm 审计 0 漏洞。
- 真实浏览器从喜欢列表同步最近 3 条成功；任务显示 3/3 完成。
- 从页面勾选已成功转写的视频再提交任务，显示 1/1 完成并保留已有逐字稿；本轮未重复执行该视频的模型推理。此前本地 Whisper 已对真实视频转写成功。
- 浏览器实际检查来源切换、搜索、逐字稿／卡片页签、卡片列表、任务中心、设置，以及重启后数据保留。
- 重复启动只显示友好提示，不中断既有任务。
- 未推送远端；未创建定时任务；启动工作台不会自动采集。

## 视觉核对

采用森林绿与白色的工作台设计参考，使用 Codex 内置浏览器验收；不需要 Playwright 截图替代。实际桌面视口为 1280×720，并检查了内置浏览器面板收窄至 524px 时的响应布局。参考图为 1536×1024，内置浏览器未提供设置该原生尺寸的接口，因此按当前实际视口核对，未声称原尺寸逐像素匹配。

核对项：

1. 布局：保留左侧导航、中央表格、右侧详情和底部任务条；窄屏切换为列表／详情。
2. 字体：中文系统字体，标题与正文有层次；长视频标题截断，详情可阅读完整标题。
3. 配色：森林绿主按钮、浅绿选中行、白色背景与浅灰边线。
4. 控件：四个导航、来源页签、搜索、同步、选择转写、任务进度均为可交互代码控件。
5. 滚动与间距：修复详情栏最小高度超过可用视口的问题，AI 总结未配置提示可见；逐字稿内部滚动。
6. 无障碍：修复窄屏导航文字隐藏后名称丢失，图标按钮保留可访问名称。

首屏文案按工作台信息架构核对。相对设计参考的有意调整：以真实本地视频替代示例；用视频／图文图标代替不存在的封面；增加状态筛选、同步条数和批量转写操作；进度使用真实条数，不提供尚未实现的取消按钮。未发现阻止本机使用的视觉问题，不宣称未验证的原尺寸完全一致。

## 使用限制

本版本面向 macOS。新视频的转写仍可能出错，需核对原视频；图文不能靠语音转写识别。任务没有中途取消按钮，停止进程后下次启动标记为中断。已有卡片可阅读和下载；新转写不会自动生成新卡片，等待下一阶段选择总结服务。
